Python 静态博客的原理

2024-06-05

上一篇讲了 这个博客是什么，这篇讲 它是怎么工作的。

核心流程

  1. 在 content/ 目录下写 HTML 片段（就是你现在看到的这些）
  2. 运行 python build.py
  3. 脚本读取所有文章，提取元信息（标题、日期）
  4. Jinja2 把内容和模板结合，渲染出完整 HTML
  5. 输出到 output/ 目录

Jinja2 做了什么

Jinja2 是 Python 最流行的模板引擎。它做的事情很简单：

  • {{ '{{ variable }}' }} — 插入变量
  • {% raw %}{% for %}...{% endfor %}{% endraw %} — 循环
  • {% raw %}{% if %}...{% endif %}{% endraw %} — 条件判断
  • {% raw %}{% block %}...{% endblock %}{% endraw %} — 模板继承

掌握了这四个语法，你就能用 Python 生成任何 HTML 页面。
