1. 核心注解

注解作用常用场景
@SpringBootApplication 组合注解 = @Configuration + @EnableAutoConfiguration + @ComponentScan 打在启动类上，一个注解搞定自动配置和包扫描
@Component 将类标记为 Spring 管理的 Bean 通用组件，说不清是哪一层时用它
@Service @Component 的语义化变体，标记业务层 Service 层实现类
@Repository @Component 的语义化变体，标记数据访问层 DAO 层，Spring 自动转换数据库异常
@Controller 标记 MVC 控制器，方法返回视图名 传统 MVC 返回页面
@RestController @Controller + @ResponseBody，方法直接返回 JSON RESTful API 控制器
@Autowired 按类型自动注入 Bean 构造器 / 字段 / Setter 注入
@Qualifier("name") 配合 @Autowired，按名称指定注入哪个 Bean 同一接口有多个实现类时
@Value("${key}") 从配置文件读取值注入字段 @Value("${server.port}")
@Bean 方法级，将返回值注册为 Spring Bean 第三方库对象的初始化（如 RestTemplate）
@Configuration 标记配置类，等价于 XML 配置文件 集中管理 @Bean 定义
@Scope 指定 Bean 的作用域 singleton（默认）、prototype、request、session
@PostConstruct Bean 初始化完成后自动执行 数据预热、连接初始化
@PreDestroy 容器销毁 Bean 前执行 释放资源、关闭连接

2. Web 请求映射

注解作用示例
@RequestMapping("/path") 映射 HTTP 请求路径到方法，可指定 method @RequestMapping(value="/user", method=RequestMethod.GET)
@GetMapping("/path") @RequestMapping(method=GET) 的简写 @GetMapping("/user/{id}")
@PostMapping("/path") @RequestMapping(method=POST) 的简写 @PostMapping("/user")
@PutMapping("/path") 对应 HTTP PUT，通常用于全量更新 @PutMapping("/user/{id}")
@DeleteMapping("/path") 对应 HTTP DELETE @DeleteMapping("/user/{id}")
@PatchMapping("/path") 对应 HTTP PATCH，通常用于部分更新 @PatchMapping("/user/{id}/password")
@PathVariable 取出 URL 路径中的变量 @GetMapping("/user/{id}") + @PathVariable Long id
@RequestParam 取出 URL 查询参数或表单参数 ?page=1&size=10 → @RequestParam int page
@RequestBody 将 HTTP 请求体的 JSON 自动反序列化为 Java 对象 @PostMapping + @RequestBody User user
@ResponseBody 方法返回值直接写入 HTTP 响应体（JSON） @RestController 已包含，单独用在 @Controller 中
@CrossOrigin 允许跨域请求（CORS） @CrossOrigin(origins = "http://localhost:3000")
@RequestHeader 取出请求头中的值 @RequestHeader("Authorization") String token

3. 参数绑定与校验

注解作用示例
@Valid 触发对入参对象的 JSR-303 校验 @PostMapping + @Valid @RequestBody User user
@NotNull 不能为 null @NotNull(message = "ID 不能为空")
@NotBlank 不能为 null 且不能全是空白字符（用于字符串） @NotBlank(message = "用户名不能为空")
@NotEmpty 不能为 null 且不能为空集合/空字符串 @NotEmpty List<Long> ids
@Size(min, max) 字符串长度或集合大小范围 @Size(min=6, max=20) String password
@Min / @Max 数值的最小 / 最大值 @Min(0) @Max(150) int age
@Email 邮箱格式校验 @Email String email
@Pattern(regexp) 正则表达式校验 @Pattern(regexp="^1[3-9]\\d{9}$") String phone
@Range(min, max) 数值范围（Hibernate Validator） @Range(min=1, max=100) int score

4. AOP 切面

注解作用说明
@Aspect 标记切面类 配合 @Component 注册到容器
@Pointcut 定义切入点表达式，给其他通知复用 @Pointcut("execution(* com.example.service.*.*(..))")
@Before 前置通知，目标方法执行前触发 权限校验、日志记录
@After 后置通知（最终），无论是否异常都执行 资源释放、清理工作
@AfterReturning 返回通知，方法正常返回后触发，可拿到返回值 缓存结果、日志记录返回值
@AfterThrowing 异常通知，方法抛出异常时触发，可拿到异常对象 异常日志、告警
@Around 环绕通知，手动控制方法执行前后逻辑，最强但最重 性能统计、事务管理、统一日志

常用切入点表达式模板：

// 所有 Service 层方法
@Pointcut("execution(* com.example.service.*.*(..))")

// 带自定义注解的方法
@Pointcut("@annotation(com.example.annotation.SysLog)")

// Controller 层所有方法
@Pointcut("execution(* com.example.controller.*.*(..))")

5. 事务与数据访问

注解作用说明
@Transactional 声明式事务，方法内数据库操作要么全成功要么全回滚 一般打在 Service 层方法上
@EnableTransactionManagement 开启注解驱动的事务管理 Spring Boot 自动配置已包含，通常不用手动加
@Mapper 标记 MyBatis 映射接口 @Mapper public interface UserMapper {}
@MapperScan("包名") 批量扫描 MyBatis Mapper 接口 打在启动类上，替代每个 Mapper 单独加 @Mapper
@Entity 标记 JPA 实体类，与数据库表映射 JPA 项目使用
@Table(name="表名") 指定实体对应的数据库表名 类名和表名不一致时用
@Id 标记主键字段 JPA 实体类必须有一个 @Id
@GeneratedValue 主键生成策略 strategy = GenerationType.IDENTITY 自增
@Column 指定字段对应的列名、长度、是否可空等 @Column(name="user_name", length=50, nullable=false)

@Transactional 常用参数：

@Transactional(
    rollbackFor = Exception.class,   // 遇到任何异常都回滚
    propagation = Propagation.REQUIRED,  // 默认传播行为
    isolation = Isolation.READ_COMMITTED,  // 隔离级别
    timeout = 30   // 超时 30 秒
)

6. 条件装配与配置

注解作用说明
@ConditionalOnClass 类路径存在指定类时才装配 自动配置底层常用，如"有 Redis 依赖才配 Redis"
@ConditionalOnMissingBean 容器中没有指定 Bean 时才装配 提供默认 Bean，用户可自定义覆盖
@ConditionalOnProperty 配置文件中有指定属性时才装配 @ConditionalOnProperty(name="feature.cache", havingValue="true")
@Profile("环境名") 指定 Bean 在哪个环境下生效 @Profile("dev") / @Profile("prod")
@ConfigurationProperties(prefix) 将配置文件属性批量绑定到 Java 对象 @ConfigurationProperties(prefix="app.jwt")
@EnableConfigurationProperties 启用指定的配置属性类 让 @ConfigurationProperties 类注册为 Bean

7. 定时与异步

注解作用示例 / 说明
@Scheduled 定时执行方法 @Scheduled(cron="0 0 3 * * ?") 每天凌晨 3 点
@EnableScheduling 开启定时任务支持 打在启动类或配置类上
@Async 方法异步执行，调用方立即返回 发邮件、推送通知等非实时操作
@EnableAsync 开启异步任务支持 打在启动类或配置类上

定时任务 Cron 常用模板：

@Scheduled(cron = "0 0 3 * * ?")    // 每天凌晨 3:00
@Scheduled(cron = "0 */30 * * * ?")  // 每 30 分钟
@Scheduled(fixedRate = 5000)         // 固定间隔 5 秒（上次开始后计时）
@Scheduled(fixedDelay = 5000)        // 固定延迟 5 秒（上次结束后计时）

8. 异常处理

注解作用说明
@ControllerAdvice 全局异常处理器，拦截所有 Controller 抛出的异常 配合 @ExceptionHandler 统一返回错误 JSON
@RestControllerAdvice @ControllerAdvice + @ResponseBody 返回 JSON 的全局异常处理
@ExceptionHandler 指定处理哪种异常 @ExceptionHandler(RuntimeException.class)
@ResponseStatus 指定响应的 HTTP 状态码 @ResponseStatus(HttpStatus.NOT_FOUND)

全局异常处理模板：

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Result handleBusiness(BusinessException e) {
        return Result.error(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public Result handleUnknown(Exception e) {
        log.error("未知异常", e);
        return Result.error(500, "服务器内部错误");
    }
}
