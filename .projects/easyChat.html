项目背景

这个项目是基于Spring Boot和Netty开发的即时聊天应用,旨在学习和实践现代Web开发技术。通过实现用户注册登录、好友管理、群组聊天和消息推送等功能,深入了解了后端开发的各个方面。

在这个过程中，掌握了 AOP 切面编程，用于统一日志、权限校验等横切关注点，显著提升了代码的可维护性；实践了 Redis 在会话缓存和消息队列中的落地应用；同时在对各类网络异常的处理中，加深了对异常体系的理解。

目录结构


easyChat/
├── src/
│   ├── main/
│   │   ├── annotation/       # 自定义注解
│   │   ├── aspect/           # AOP 切面
│   │   ├── controller/       # 控制器层
│   │   ├── entity/           # 实体类
│   │   ├── exception/        # 异常处理
│   │   ├── mappers/          # MyBatis 数据映射
│   │   ├── redis/            # Redis 配置与工具
│   │   ├── service/          # 业务逻辑层
│   │   ├── utils/            # 通用工具类
│   │   ├── websocket/        # WebSocket 通信
│   │   ├── EasyChatApplication.java  # Spring Boot 启动类
│   │   └── InitRun.java              # 应用初始化
│   └── resources/            # 配置文件 (application.yml, mybatis 的配置等)
└── pom.xml
