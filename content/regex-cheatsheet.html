1. 基础元字符

符号 含义 示例 匹配

\ 转义字符 \. 字面句号 .
\| 或 cat\|dog cat 或 dog

2. 字符类

语法 含义 示例 匹配
[abc] a、b、c 中任意一个 [ae]llo allo, ello
[a-z] a 到 z 任意一个小写字母 [a-z] a, b, ..., z
[0-9] 0 到 9 任意一个数字 \d 等价 0, 1, ..., 9
[a-zA-Z] 任意大小写字母 — A, b, Z
[^abc] 不是 a、b、c 的任意字符 [^0-9] 非数字字符
\d 数字 [0-9] \d{3} 123, 456
\D 非数字 [^0-9] — a, X, 空格
\w 单词字符 [a-zA-Z0-9_] \w+ hello, var_1
\W 非单词字符 [^a-zA-Z0-9_] — @, !, 空格
\s 空白字符（空格、Tab、换行等） a\s*b ab, a b, a b
\S 非空白字符 — 任何可见字符
\n 换行符 — —
\t Tab — —

3. 量词

语法 含义 示例 匹配
* 0 次或多次 ab*c ac, abc, abbbc
+ 1 次或多次 ab+c abc, abbbc（不匹配 ac）
? 0 次或 1 次 ab?c ac, abc
{n} 恰好 n 次 \d{4} 4 位数字
{n,} 至少 n 次 \d{4,} 4 位及以上数字
{n,m} n 到 m 次 \d{2,4} 2 到 4 位数字

4. 分组与捕获

语法 含义 示例
(...) 捕获分组，可通过 group(1) 取出 (\d{4})-(\d{2})-(\d{2}) 匹配 2024-06-01 → group(1) = 2024
(?:...) 非捕获分组，只做逻辑分组不存 (?:http\|https)://
(?P<name>...) 命名分组，Python 支持 (?P<year>\d{4}) → group("year")
\1, \2 反向引用，引用前面的分组 (\w+)\s+\1 匹配 hello hello

5. 锚点

语法 含义 说明
^ 行首 ^Hello 只匹配开头的 Hello
$ 行尾 end$ 只匹配结尾的 end
\b 单词边界 \bcat\b 匹配独立的 cat，不匹配 catalog
\B 非单词边界 —

6. 环视（零宽度断言）

语法 含义 示例
(?=...) 后面跟着... \w+(?=@) 匹配邮箱的 @ 前部分
(?!...) 后面不是... \d{3}(?!\d) 恰好 3 位数字，后面不能是数字
(?<=...) 前面有... (?<=@)\w+ 匹配邮箱的域名部分
(?<!...) 前面没有... (?<!\$)\d+ 匹配前面没有 $ 的数字

"零宽度" 意思是只检查、不消费字符——匹配结果里不包含环视部分。

8. 贪婪 vs 非贪婪

模式 含义 示例 匹配结果
.* 贪婪——尽量多匹配 <p>hello</p> 对 <(.*)> 捕获p>hello</p
.*? 非贪婪——尽量少匹配 <p>hello</p> 对 <(.*?)> 捕获p

9. 常见场景模板

场景 正则 说明
HTML 注释 <!--.*?--> re.DOTALL + 非贪婪
HTML 标签 <[^>]+> 匹配开始/结束/自闭合标签
去除 HTML 标签 re.sub(r'<[^>]+>', '', s) 替换为空
提取 key: value (\w+):\s*(.+) key 是单词字符，\s* 允许冒号后空格
邮箱 [\w.-]+@[\w.-]+\.\w+ 基础版
URL https?://[\w./-]+ 基础版
日期 YYYY-MM-DD \d{4}-\d{2}-\d{2} 基础格式匹配
中文 [一-鿿] Unicode 汉字范围
纯数字串 ^\d+$ 整行都是数字
首尾无空格 ^\S.*\S$\|^\S$ 或 Python 直接用 s.strip()
提取文件名 [^/\\]+$ 路径最后一段
提取扩展名 \.(\w+)$ 比如 .pdf → pdf
密码强度 ^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}$ 至少 8 位，含大小写 + 数字

10. Python re模块标志

标志 简写 含义
re.IGNORECASE re.I 忽略大小写
re.MULTILINE re.M ^ 和 $ 匹配每行的首尾，而非整个字符串首尾
re.DOTALL re.S . 也能匹配换行符 \n
re.VERBOSE re.X 允许在正则里写注释和空格（增强可读性）
